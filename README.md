# Performance Tracking: Excel OLAP Refresh Automation
Автоматизированный инструмент для массового обновления таблиц в Excel, подключенных к OLAP-кубам через ODC-ссылки. Скрипт разработан для обработки большого объема файлов (200+) в рамках процесса Performance Tracking.
## Особенности архитектуры
Обновление OLAP-соединений через win32com часто приводит к зависанию процессов Excel или утечкам памяти. Для решения этой проблемы скрипт использует следующую архитектуру:
1. **Изоляция процессов:** Каждый файл открывается и обновляется в отдельном дочернем процессе Python (subprocess).
2. **Обработка таймаутов:** Если обновление куба зависает, дочерний процесс принудительно завершается по таймауту (по умолчанию 600 секунд), что предотвращает блокировку основного скрипта.
3. **Асинхронное ожидание:** Используется CalculateUntilAsyncQueriesDone() для корректного ожидания завершения фоновых запросов к кубу.
4. **Детальное логирование:** По итогам работы формируется текстовый отчет с перечнем файлов, которые не удалось обновить, и причинами сбоев.
## Требования
- **ОС:** Windows (требуется установленный Microsoft Excel).
- **Python:** 3.8 или выше.
- **Доступ:** Права на чтение/запись файлов и доступ к OLAP-кубу.
## Установка
1. Клонируйте репозиторий или скачайте его как ZIP-архив.
2. Создайте виртуальное окружение и активируйте его:
  python -m venv venv
  venv\Scripts\activate
3. Установите зависимости:
  pip install -r requirements.txt
## Использование
Скрипт поддерживает как интерактивный режим, так и запуск с аргументами (для автоматизации).
### Интерактивный режим
Запустите скрипт без аргументов. Он запросит путь к папке и фильтр по месяцу:
python src/refresh_excel.py
### Автоматизированный режим (с аргументами)
Передайте путь и месяц через аргументы командной строки. Это необходимо для запуска через Планировщик задач Windows.
python src/refresh_excel.py --path "C:\Path\To\Excel\Files" --month "May'26"
Если аргумент --month не указан, будут обработаны все файлы в директории.
## Настройка параметров
Основные настройки находятся в начале файла src/refresh_excel.py:
- TIMEOUT_SECONDS: Максимальное время ожидания обновления одного файла в секундах (по умолчанию 600).
- EXCEL_VISIBLE: Флаг видимости окна Excel. Для фоновой автоматизации рекомендуется установить False.
## Структура выходных данных
В случае наличия ошибок, в корневой папке с обрабатываемыми файлами будет создан лог failed_files_log.txt, содержащий:
- Дату и время запуска.
- Общую статистику (успех/ошибки).
- Детальный список проблемных файлов с указанием полного пути и текста ошибки.

## Устранение неполадок
- **Ошибка COM / Excel не отвечает:** Увеличьте TIMEOUT_SECONDS. Возможно, куб выполняет тяжелые вычисления.
- **Файл не сохраняется (ошибка прав):** Убедитесь, что файлы не открыты другими пользователями и у скрипта есть права на запись в директорию.
- **Ошибки ODC подключения:** Проверьте, что сетевое подключение к серверу OLAP активно и учетные данные Windows корректны.
